# VocaFlow V11.3

Neu im 1×1-Modul:
- Lernhilfe zu jeder Aufgabe 2×1 bis 10×10
- Daten getrennt in data/mathHints.json
- drei Hilfestufen:
  - Anfänger: Strategie + Erklärung + Merksatz
  - Üben: nur Strategie
  - Können: Hilfe zunächst verborgen
- Strategien u. a.:
  - Verdoppeln
  - doppelt verdoppeln
  - 5er + 1
  - 5er + 2
  - 5er + 3
  - 10er minus einmal
- besondere Merkhilfen für schwierige Aufgaben wie 6×7, 6×8, 7×8, 8×9
- Hilfestufe bleibt auf dem Gerät gespeichert

Die Hilfen sind bewusst als erste Testversion angelegt und können nach dem Praxistest mit den Kindern einfach in mathHints.json angepasst werden.
