# VocaFlow V11.4 – 1×1 auswendig lernen

Neu:
- eigener Bereich „1×1 auswendig lernen“
- Blitzkarten:
  Aufgabe → Karte antippen → Lösung → Gewusst / Noch einmal
- Glücksrad:
  Rad dreht animiert und wählt die nächste Lernkarte
- Rhythmusmodus:
  Aufgabe und Ergebnis werden als kurzer Rhythmussatz gesprochen
- schwierige Karten werden innerhalb derselben Runde schneller erneut gezeigt
- pro Profil wird separat gespeichert, welche Malaufgaben oft gewusst bzw. wiederholt wurden
- richtige Karten bringen kleine XP/Belohnungen
- funktioniert mit Katzen- und Fußballprofilen
- bestehende Lernhilfen Anfänger / Üben / Können bleiben erhalten

Die drei Modi sind bewusst als erste Testversion gedacht. Nach dem Test mit den Kindern können Geschwindigkeit, Optik und Wiederholungslogik gezielt angepasst werden.
